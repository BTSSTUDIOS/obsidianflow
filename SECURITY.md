# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The OBSIDIAN FLOW team takes security seriously. If you discover a vulnerability or security flaw, please report it privately:

1. **Do NOT** open a public issue on GitHub.
2. Email your report to **`bidkar@gulp.wtf`**.
3. Include detailed steps to reproduce the issue, proof of concept, and any affected configurations.

We will acknowledge receipt within 48 hours and work with you to remediate the issue promptly.
