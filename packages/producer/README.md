# @obsidianflow/producer

> **FFmpeg video encoding and audio mixing pipeline for OBSIDIAN FLOW**

Part of the [OBSIDIAN FLOW](https://github.com/btsstudios/obsidianflow) monorepo.

## Installation

```bash
npm install @obsidianflow/producer
```

## Features

- **FFmpeg image2pipe Streaming**: Direct pipe from Puppeteer raw PNG buffers to FFmpeg stdin.
- **Sidechain Audio Ducking**: Automatic dialogue ducking filtergraphs for background music tracks.
- **Multi-Format Transcoding**: Production presets for H.264, ProRes, VP9, and AV1.
